# Poli Exclusive Sakinah — Frontend

Aplikasi registrasi pasien, konfirmasi booking, antrean, data pasien, dan laporan.
Frontend statis (HTML/CSS/JS tanpa dependensi) + backend Google Apps Script (REST API).

1. Isi `GAS_URL` di `js/config.js`.
2. Deploy folder ini ke GitHub Pages (root repository = folder ini).
3. Ikuti `PANDUAN-INSTALASI.md` untuk pemasangan backend dan pengaturan awal.
